# Getting help with Towns & Kingdoms Workshop

Use the [issue tracker](https://github.com/Mikaaah/Towns-and-Kingdoms-Workshop/issues) for reproducible problems and feature requests. For setup questions and sharing your builds, join [Discord](https://discord.gg/CRYk3uDPVt).

## A useful bug report

1. Give the Minecraft, loader and mod versions, plus relevant companion mods.
2. Describe what you expected and what happened.
3. List the shortest steps that reproduce the problem.
4. Attach the relevant log or crash report. Screenshots help with rendering and interface problems.

Check the [player guide](https://github.com/Mikaaah/Towns-and-Kingdoms-Workshop/wiki) and existing issues first. Keep passwords, access tokens and private server addresses out of attachments.
