# Getting started

Requires Java 21 and NeoForge 21.1.219+ within 21.1.x. Install matching Workshop versions on the server and every client. Stable namespace: `tnkcore`. Read the [README](https://github.com/Mikaaah/Towns-and-Kingdoms-Workshop#readme) for recipes and controls.
