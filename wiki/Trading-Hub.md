# Trading Hub — TNK3 edition

The Trading Hub is the pack's Waystones-backed directory for shops and personal destinations. It is present in the TNK3 Workshop build; the older public 0.6.1 source does not contain it.

Use the questbook's acquisition route, place the block and enter the destination name, description and icon. Browse or search the directory, open a listing and use **Teleport**. Manage your own listings through their editor.

The stable reward item is `tnkcore:trade_sharestone`. Server settings in `tnkcore-market-server.toml` control text limits, cooldowns and icons. A directory destination helps visitors reach a shop; the shop's item and currency exchange uses the installed trading system.
