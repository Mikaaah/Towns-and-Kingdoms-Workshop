✦ WORKSHOP — 1.1.0 ✦

Your adventure, reflected in Discord.

Minecraft 1.21.1 · NeoForge · Java 21

Customizable presence profiles

  • Added separate Discord Rich Presence profiles for loading, the main menu, browsing servers and worlds, joining games, singleplayer, multiplayer and disconnection.
  • Customize both text lines, large and small images, image hover text, buttons and elapsed-time display for each profile.
  • Rotate between multiple messages and artwork using configurable intervals.
  • Added profile editing, copy, paste and reset controls, alongside local text previews.

More context from your world

  • Added placeholders for player names, world names, server display names, online player counts, Minecraft version and installed mod count.
  • Retains Workshop’s factory-area names, viewed or pinned FTB quests, chapter progress and gameplay activities.
  • Added activity messages for browsing the Community Board and Trading Hub.
  • Added dimension and biome overrides, allowing different locations to use their own text, artwork and buttons.
  • Overrides inherit unspecified settings from the active profile, so shared branding only needs configuring once.

TK3 branding & BisectHosting

  • Configured the supplied TK3 Discord application with matching TNK3 and BisectHosting artwork keys.
  • Added default Modpack and Get a Server buttons.
  • Added configurable BisectHosting promotional text featuring code Mika.
  • Branding, promotional wording, artwork and links remain editable.

Configuration & sharing controls

  • Added reusable custom variables and support for legacy %player%-style placeholders within the expanded profiles.
  • Added individual sharing controls for player names, world names, server names and online player counts.
  • Server information uses the server’s display name; addresses and ports are not published.
  • Existing presence configurations retain their custom wording, artwork and application settings in legacy mode.
  • Language-file overrides remain supported through resource packs and KubeJS assets.

Open Mods → Workshop → Config or use /workshop presence. Existing users can enable Use profiles or install the supplied TK3 presence configuration.

Update both client and server to 1.1.0. Existing Waystones and Balm requirements are unchanged.
